
# SpaceOS App Catalog

Modern futuristic workspace / app catalog dashboard.

## Features
- Mosaic/Grid view
- Space/Tree explorer
- Search + filters
- JSON database
- Lightweight AIO architecture
- GitHub Pages ready
- Tailwind-like design system
- Vanilla JS

## Run
Open `index.html`
